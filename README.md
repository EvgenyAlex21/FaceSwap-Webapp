# Local Face Swap

<p align="center">
  <b>Полностью локальная замена лиц, AI-редактор фото и анимация изображений</b><br>
  Слоты лиц · Сохранение звука · Пресеты качества · Выделение (инпейнт) · Редактор по промпту · Оживление фото
</p>

---

## Возможности

| Вкладка | Функция | Описание |
|---------|---------|----------|
| **Фото** | Замена лиц на фото | Автоматический поиск до 6 лиц на целевом фото, для каждого — отдельное фото-источник. Резкость, апскейл по длинной стороне (до 4K), PNG/JPG |
| **Видео** | Замена лиц в видео | Быстрое сканирование сегмента, уникальные лица по косинусному сходству эмбеддингов, выбор «чей ↔ кому», фрагмент по времени, сохранение звука, выбор разрешения/FPS/CRF |
| **Выделение** | AI-инпейнт по маске | Закрасьте область кистью — диффузионная модель перерисует её. Локальные .safetensors-модели (SD 1.5 inpaint, SDXL, TryOffAnyone) плюс быстрый OpenCV-инпейнт (Telea/NS) |
| **Редактор** | Правка фото текстом | FLUX.2 klein 4B (GGUF, дистиллированная, 4 шага) или InstructPix2Pix. Перевод промпта RU→EN офлайн |
| **Преображение** | Оживление фото | Stable Video Diffusion (SVD-XT): фото → видео до 4 секунд (25 кадров @ 6 fps). Описанное промптом сначала генерируется как первый кадр через SD 1.5 |

Вся обработка выполняется **офлайн** после загрузки моделей: нет облачных API, водяных знаков и лимитов использования.

## Системные требования

| Компонент | Минимум | Рекомендуется |
|-----------|---------|---------------|
| ОС | Windows / Linux / macOS | Windows 10–11 x64 |
| Python | 3.10 – 3.12 | 3.11 |
| RAM | 16 ГБ | 32 ГБ |
| GPU | — (работает на CPU) | NVIDIA, 4–6+ ГБ VRAM |
| Диск | 1 ГБ (face-swap) | 30+ ГБ (все модели) |

### Face swap (InsightFace / InSwapper)

- **NVIDIA GPU**: автоматическая детекция CUDA для `onnxruntime-gpu`. Требуется CUDA 12 runtime + cuDNN 9 (ставятся как pip-пакеты, см. ниже). При проблемах — автоматический fallback на CPU.
- **CPU / AMD / Intel**: работает из коробки через `CPUExecutionProvider` (медленнее).
- Приложение само проверяет провайдеры, делает тестовую сессию на `inswapper_128.onnx` и пишет подробную диагностику в лог (`[GPU] ---- ОТЛАДКА ----`).

### Диффузия (инпейнт / редактор / анимация)

- Требуется **NVIDIA GPU с CUDA** (проверяется `torch.cuda.is_available()`). На чистом CPU эти вкладки не запускаются — будет понятная ошибка.
- Оптимизировано под **4 ГБ VRAM**: FP16, `enable_model_cpu_offload` / последовательный offload, VAE tiling/slicing, chunking UNet, лесенка отката разрешения при OOM (редактор и аниматор автоматически уменьшают размер и повторяют попытку).
- **VRAM-менеджер**: одновременно держится только одна тяжёлая модель. Перед запуском инпейнта/редактора/анимации face-swap и прочие модели автоматически выгружаются, после работы — тоже.

## Быстрый старт

```bash
git clone <your-repo-url> FaceSwap-Webapp
cd FaceSwap-Webapp

python -m venv venv

# Windows
venv\Scripts\activate

# Linux / macOS
# source venv/bin/activate

pip install -r requirements.txt
python -m app.download_models          # только face-swap (~0.6 ГБ)
python app/main.py
```

Откройте **http://127.0.0.1:7860**

> Если модели не скачаны заранее, приложение попытается скачать их само при первом запуске соответствующей вкладки (нужен интернет один раз).

## Загрузка моделей — все флаги

| Команда | Что скачивает | Размер |
|---------|--------------|--------|
| `python -m app.download_models` | buffalo_l (детекция лиц) + inswapper_128 | ~0.6 ГБ |
| `--inpaint` | Realistic Vision SD 1.5 inpaint, LUSTIFY SDXL, TryOffAnyone | ~4–6 ГБ |
| `--editor` | FLUX.2 klein 4B (энкодер/VAE + GGUF Q4_K_M) | ~12 ГБ |
| `--ip2p` | InstructPix2Pix | ~5 ГБ |
| `--animate` | Stable Video Diffusion (SVD-XT) | ~9 ГБ |
| `--translate` | Helsinki opus-mt-ru-en (перевод промптов RU→EN) | ~0.3 ГБ |
| `--all` | всё перечисленное | ~30 ГБ |
| `--force` | перекачать существующие файлы | — |

Скачивание возобновляется после обрыва. Модели сохраняются в `models/`.

## Настройка NVIDIA GPU (Windows)

Face swap (`onnxruntime-gpu`) и диффузия (`torch`) требуют CUDA 12 + cuDNN 9:

```bash
pip install onnxruntime-gpu==1.20.2
pip install nvidia-cublas-cu12 nvidia-cuda-runtime-cu12 nvidia-cudnn-cu12 nvidia-cuda-nvrtc-cu12
```

Для диффузии обязательно ставьте версию PyTorch с CUDA:

```bash
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu124
```

Проверка:

```bash
python -c "import onnxruntime as ort; print(ort.get_available_providers())"
python -c "import torch; print(torch.__version__, torch.cuda.is_available())"
```

В консоли при запуске должно появиться:

```text
[GPU] CUDA: OK — face-swap на видеокарте
```

На Linux/macOS достаточно обычного `pip install onnxruntime-gpu torch` (torch с индексом cu124 для NVIDIA Linux).

## Типичные проблемы и их решение

### 1. `LoadLibrary failed with error 126` / CUDA переключается на CPU
Отсутствуют cuDNN или CUDA DLL:

```bash
pip install nvidia-cudnn-cu12 nvidia-cublas-cu12 nvidia-cuda-runtime-cu12 nvidia-cuda-nvrtc-cu12
```

**Не удаляйте** `nvidia-cudnn-cu12`, если нужен CUDA для ORT.

### 2. Torch: `Error loading cudnn_cnn64_9.dll` (WinError 127)
Конфликт cuDNN из pip-пакета и встроенного cuDNN в torch. Предзагрузка torch в приложении уже решает это; если всё равно возникает:

```bash
pip uninstall torch torchvision torchaudio nvidia-cudnn-cu12 -y
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu124
pip install nvidia-cudnn-cu12
```

### 3. В видео нет звука
- Держите включённым чекбокс **«Сохранять звук»**.
- Звук подмешивается через встроенный ffmpeg (`imageio-ffmpeg`). Если дорожка всё равно теряется, проверьте, что в исходнике она есть, и что выбран фрагмент с аудио.

### 4. Превью в браузере пустое
Браузеру нужен H.264 (`yuv420p`) — вывод всегда перекодируется через ffmpeg. Готовые файлы ищите в папке `outputs/`.

### 5. «Выделение» / «Редактор» / «Преображение» падают с `OutOfMemoryError`
- Для SDXL (LUSTIFY) нужно ≥ 2.8 ГБ свободной VRAM — используйте **Realistic Vision (SD 1.5)** на картах с 4 ГБ.
- Редактор и аниматор сами снижают разрешение при OOM, но для надёжности выберите меньший размер и закройте другие GPU-приложения (браузер с аппаратным ускорением, игры).
- Модели конкурируют за память: приложение выгружает предыдущую, но после серьёзного OOM иногда помогает перезапуск.

### 6. «Модель не найдена» при первом запуске вкладки
Запустите соответствующую загрузку: `python -m app.download_models --inpaint / --editor / --animate / --translate`. Скрипт идемпотентен — уже скачанные файлы пропускаются.

### 7. FLUX.2 klein не загружается (ошибка GGUF/трансформера)
Обновите `diffusers`, `transformers`, `gguf` (`pip install -U diffusers transformers gguf`) или переключитесь на **InstructPix2Pix** в выпадающем списке модели.

### 8. Медленная работа на CPU
Это ожидаемо: face swap на CPU делает доли кадра в секунду. Для первых тестов используйте детекцию **«Быстрый (320)»**, обработку каждого 2–3-го кадра и CRF 23–26.

### 9. Антивирус / SmartScreen
Приложение локально, без сети после загрузки моделей. Если SmartScreen блокирует vv .bat-файлы, добавьте папку проекта в исключения.

## Рекомендуемые настройки качества

Для лучшего визуального результата (медленнее):

| Параметр | Значение |
|----------|----------|
| Детекция лиц | **Качественный (640)** или **Максимум (800)** |
| Резкость | **Среднее** или **Сильное** |
| Разрешение видео | **Как есть** или **Full HD (1080p)** |
| Качество видео | **Высокое (CRF 18)** или **Хорошее (CRF 20)** |
| Детекция кадров | **1** (каждый кадр) |

Для быстрого черновика:

- Детекция **320–480**
- Каждые **2–3** кадра
- CRF **23–26**

## Как пользоваться вкладкой «Видео»

1. Загрузите фото с лицом-источником и нажмите **«Найти лица на фото»**.
2. Загрузите видео и задайте ползунками начало/конец фрагмента.
3. Нажмите **«Найти лица в видео (быстро)»** — сканируются кадры сегмента, уникальные люди группируются по сходству эмбеддингов (порог 0.5).
4. В разделе **«Сопоставление лиц»** выберите, чьё лицо вставляем (из фото) и кому (в видео).
5. Нажмите **«Заменить лица в видео»**.

## Чек-лист диагностики

```bash
# Провайдеры ONNX
python -c "import onnxruntime as ort; print(ort.__version__, ort.get_available_providers())"

# Torch CUDA
python -c "import torch; print(torch.__version__, torch.cuda.is_available())"

# Видна ли GPU?
nvidia-smi
```

Если CUDA в списке провайдеров есть, но face-swap уходит на CPU — смотрите блок `[GPU] ---- ОТЛАДКА ----` в логах при запуске: там видны результат тестовой сессии, найденные nvidia-пакеты и точная причина.

## Лицензия и модели
