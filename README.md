# FaceSwap Webapp

<p align="center">
  <b>Полностью локальная замена лиц, AI-редактор фото и анимация изображений</b><br>
  Слоты лиц · Сохранение звука · Пресеты качества · Выделение (инпейнт) · Редактор по промпту · Оживление фото
</p>

> Обрабатывайте только изображения и видео, на использование которых у вас есть права и согласие изображённых людей. Не используйте приложение для обмана, выдачи синтетических материалов за подлинные или нарушения приватности.

Локальное приложение на Gradio для замены лиц на фотографиях и видео, AI-инпейнта, редактирования изображений по текстовому запросу и анимации фотографий.

---

## Возможности

| Вкладка | Функция | Описание |
|---------|---------|----------|
| **Фото** | Замена лиц на фото | Автоматический поиск до 6 лиц на целевом фото, для каждого — отдельное фото-источник. Резкость, апскейл по длинной стороне (до 4K), PNG/JPG, выбор качества и формата результата |
| **Видео** | Замена лиц в видео | Быстрое сканирование сегмента, уникальные лица по косинусному сходству эмбеддингов, выбор «чей ↔ кому», фрагмент по времени, сохранение звука, выбор разрешения/FPS/CRF |
| **Выделение** | AI-инпейнт по маске | Закрасьте область кистью — диффузионная модель перерисует её. Локальные .safetensors-модели (SD 1.5 inpaint, SDXL, TryOffAnyone) плюс быстрый OpenCV-инпейнт (Telea/NS) |
| **Редактор** | Правка фото текстом | FLUX.2 klein 4B (GGUF, дистиллированная, 4 шага) или InstructPix2Pix. Перевод промпта RU→EN офлайн |
| **Преображение** | Оживление фото | Stable Video Diffusion (SVD-XT): фото → видео до 4 секунд (25 кадров @ 6 fps). Описанное промптом сначала генерируется как первый кадр через SD 1.5 |

Вся обработка выполняется **офлайн** после загрузки моделей: нет облачных API, водяных знаков и лимитов использования. Для первоначальной установки моделей требуется интернет.

## Системные требования

| Компонент | Минимум | Рекомендуется |
|-----------|---------|---------------|
| ОС | Windows / Linux | Windows 10–11 x64 |
| Python | 3.10 – 3.12 | 3.11 |
| RAM | 16 ГБ | 32 ГБ |
| GPU | — (замена лиц работает на CPU) | NVIDIA, 4–6+ ГБ VRAM |
| Диск | 1 ГБ (face-swap) | 30+ ГБ (все модели) |

Другие платформы (macOS и т.п.) могут требовать самостоятельной настройки зависимостей.

- Для вкладок **Выделение**, **Редактор** и **Преображение** требуется NVIDIA GPU с CUDA — на чистом CPU эти вкладки не запускаются, будет понятная ошибка.
- NVIDIA GPU ускоряет замену лиц; при недоступности CUDA обработка автоматически переходит на CPU.

### Face swap (InsightFace / InSwapper)

- **NVIDIA GPU**: автоматическая детекция CUDA для `onnxruntime-gpu`. Требуется CUDA 12 runtime + cuDNN 9 (ставятся как pip-пакеты, см. ниже). При проблемах — автоматический fallback на CPU.
- **CPU / AMD / Intel**: работает из коробки через `CPUExecutionProvider` (медленнее).
- Приложение само проверяет провайдеры, делает тестовую сессию на `inswapper_128.onnx` и пишет подробную диагностику в лог (`[GPU] ---- ОТЛАДКА ----`).

### Диффузия (инпейнт / редактор / анимация)

- Требуется **NVIDIA GPU с CUDA** (проверяется `torch.cuda.is_available()`).
- Оптимизировано под **4 ГБ VRAM**: FP16, `enable_model_cpu_offload` / последовательный offload, VAE tiling/slicing, chunking UNet, лесенка отката разрешения при OOM (редактор и аниматор автоматически уменьшают размер и повторяют попытку).
- **VRAM-менеджер**: одновременно держится только одна тяжёлая модель. Перед запуском инпейнта/редактора/анимации face-swap и прочие модели автоматически выгружаются, после работы — тоже.

## Установка и запуск

```bash
git clone https://github.com/EvgenyAlex21/FaceSwap-Webapp.git
cd FaceSwap-Webapp

python -m venv .venv

# Windows PowerShell
.venv\Scripts\Activate.ps1

# Linux
# source .venv/bin/activate

python -m pip install --upgrade pip
pip install -r requirements.txt

# Скачать базовые модели для замены лиц (~0.6 ГБ)
python download_models.py

# Запустить приложение
python -m app.main
```

Откройте **http://127.0.0.1:7860**

Приложение запускается на локальном интерфейсе `127.0.0.1` и не включает публичный Gradio Share.

> Если модели не скачаны заранее, приложение попытается скачать их само при первом запуске соответствующей вкладки (нужен интернет один раз).

## Загрузка дополнительных моделей

Запускайте команды из корневой папки репозитория. Базовые модели Face Swap загружаются всегда; флаги добавляют соответствующие наборы:

| Команда | Что скачивает | Размер |
|---------|--------------|--------|
| `python download_models.py` | buffalo_l (детекция лиц) + inswapper_128 | ~0.6 ГБ |
| `python download_models.py --inpaint` | Realistic Vision SD 1.5 inpaint, LUSTIFY SDXL, TryOffAnyone | ~4–6 ГБ |
| `python download_models.py --editor` | FLUX.2 klein 4B (энкодер/VAE + GGUF Q4_K_M) | ~12 ГБ |
| `python download_models.py --ip2p` | InstructPix2Pix | ~5 ГБ |
| `python download_models.py --animate` | Stable Video Diffusion (SVD-XT) | ~9 ГБ |
| `python download_models.py --translate` | Helsinki opus-mt-ru-en (перевод промптов RU→EN) | ~0.3 ГБ |
| `python download_models.py --all` | Всё перечисленное | ~30 ГБ |
| Добавить `--force` | Принудительно перекачать существующие базовые файлы | — |

Скачивание возобновляется после обрыва. Загрузчик идемпотентен — уже существующие файлы подходящего размера пропускаются. Модели сохраняются в `models/` в корне проекта. Генерируемые результаты сохраняются в `outputs/`.

## Настройка NVIDIA GPU (Windows)

Face swap (`onnxruntime-gpu`) и диффузия (`torch`) требуют совместимых версий драйвера NVIDIA, CUDA и cuDNN. Конкретные версии зависят от платформы и установленной версии PyTorch. Один из вариантов установки runtime-пакетов:

```bash
pip install onnxruntime-gpu==1.20.2
pip install nvidia-cublas-cu12 nvidia-cuda-runtime-cu12 nvidia-cudnn-cu12 nvidia-cuda-nvrtc-cu12
```

Для диффузии обязательно ставьте версию PyTorch с CUDA (пример для CUDA 12.4):

```bash
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu124
```

Проверка окружения:

```bash
python -c "import onnxruntime as ort; print(ort.__version__, ort.get_available_providers())"
python -c "import torch; print(torch.__version__, torch.cuda.is_available())"
nvidia-smi
```

В консоли при запуске должно появиться:

```text
[GPU] CUDA: OK — face-swap на видеокарте
```

На Linux достаточно обычного `pip install onnxruntime-gpu torch` (для NVIDIA Linux — torch с индексом cu124).

Если CUDA-провайдер недоступен, замена лиц может перейти на CPU. Генеративные вкладки требуют доступной CUDA.

## Типичные проблемы и их решение

### 1. `LoadLibrary failed with error 126` / CUDA переключается на CPU
Отсутствуют cuDNN или CUDA DLL:

```bash
pip install nvidia-cudnn-cu12 nvidia-cublas-cu12 nvidia-cuda-runtime-cu12 nvidia-cuda-nvrtc-cu12
```

**Не удаляйте** `nvidia-cudnn-cu12`, если нужен CUDA для ORT.

### 2. Torch: `Error loading cudnn_cnn64_9.dll` (WinError 127)
Конфликт cuDNN из pip-пакета и встроенного cuDNN в torch. Предзагрузка torch в приложении уже решает это; если всё равно возникает:

```bash
pip uninstall torch torchvision torchaudio nvidia-cudnn-cu12 -y
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu124
pip install nvidia-cudnn-cu12
```

### 3. В видео нет звука
- Держите включённым чекбокс **«Сохранять звук»**.
- Звук подмешивается через встроенный ffmpeg (`imageio-ffmpeg`). Если дорожка всё равно теряется, проверьте, что в исходнике она есть, и что выбран фрагмент с аудио.

### 4. Превью в браузере пустое
Браузеру нужен H.264 (`yuv420p`) — вывод всегда перекодируется через ffmpeg. Готовые файлы ищите в папке `outputs/`.

### 5. «Выделение» / «Редактор» / «Преображение» падают с `OutOfMemoryError`
- Для SDXL (LUSTIFY) нужно ≥ 2.8 ГБ свободной VRAM — используйте **Realistic Vision (SD 1.5)** на картах с 4 ГБ.
- Редактор и аниматор сами снижают разрешение при OOM, но для надёжности выберите меньший размер и закройте другие GPU-приложения (браузер с аппаратным ускорением, игры).
- Модели конкурируют за память: приложение выгружает предыдущую, но после серьёзного OOM иногда помогает перезапуск.

### 6. «Модель не найдена» при первом запуске вкладки
Запустите соответствующую загрузку:

```bash
python download_models.py --inpaint   # или --editor / --ip2p / --animate / --translate
```

Скрипт идемпотентен — уже скачанные файлы пропускаются.

### 7. FLUX.2 klein не загружается (ошибка GGUF/трансформера)
Обновите `diffusers`, `transformers`, `gguf` (`pip install -U diffusers transformers gguf`) или переключитесь на **InstructPix2Pix** в выпадающем списке модели.

### 8. Медленная работа на CPU
Это ожидаемо: face swap на CPU делает доли кадра в секунду. Для первых тестов используйте детекцию **«Быстрый (320)»**, обработку каждого 2–3-го кадра и CRF 23–26.

### 9. Антивирус / SmartScreen
Приложение локально, без сети после загрузки моделей. Если SmartScreen блокирует .bat-файлы, добавьте папку проекта в исключения.

## Рекомендуемые настройки качества

Для лучшего визуального результата (медленнее):

| Параметр | Значение |
|----------|----------|
| Детекция лиц | **Качественный (640)** или **Максимум (800)** |
| Резкость | **Среднее** или **Сильное** |
| Разрешение видео | **Как есть** или **Full HD (1080p)** |
| Качество видео | **Высокое (CRF 18)** или **Хорошее (CRF 20)** |
| Детекция кадров | **1** (каждый кадр) |

Для быстрого черновика:

- Детекция **320–480**
- Каждые **2–3** кадра
- CRF **23–26**

## Пошаговые инструкции

### 📷 Вкладка «Фото»

> Замена одного или нескольких лиц на целевом снимке.

1. При необходимости настройте **Параметры обработки** (детекция, резкость, формат, размер). Значения по умолчанию подходят для большинства случаев.
2. Загрузите **целевое фото** и нажмите **«Найти лица»** — до 6 лиц, каждое получит свой слот с превью.
3. В каждый нужный слот загрузите **фото человека, чьё лицо подставить**, и нажмите **«Найти лицо»**, чтобы проверить превью.
4. Нажмите **«Заменить лица»**. Результат появится ниже и сохранится в `outputs/`.

### 🎬 Вкладка «Видео»

> Замена лиц в фрагменте видео с сохранением звука.

1. Загрузите фото с лицом-источником и нажмите **«Найти лица на фото»**.
2. Загрузите видео и задайте ползунками начало/конец фрагмента.
3. Нажмите **«Найти лица в видео (быстро)»** — сканируются кадры сегмента, уникальные люди группируются по сходству эмбеддингов (порог 0.5).
4. В разделе **«Сопоставление лиц»** выберите, чьё лицо вставляем (из фото) и кому (в видео).
5. Нажмите **«Заменить лица в видео»**.

### 🖌 Вкладка «Выделение»

> AI-инпейнт: перерисовка закрашенной области. Нужен GPU.

1. Загрузите изображение и **закрасьте кистью** область для изменения.
2. Выберите метод: **OpenCV** (мгновенно, простое заполнение) или **диффузию**.
3. Для диффузии выберите модель (на 4 ГБ VRAM — **Realistic Vision SD 1.5**), при желании впишите позитивный/негативный промпт, задайте шаги, guidance, strength и seed.
4. Запустите обработку. Приложение само выгрузит остальные модели, диффузия аккуратно впишется в края маски.

### ✏️ Вкладка «Редактор»

> Правка фото текстовой командой. Нужен GPU.

1. Загрузите фото и опишите изменение словами — можно **на русском**, промпт переведётся офлайн (например: «Замени фон на закат на морском берегу»).
2. Выберите модель:
   - **FLUX.2 klein 4B** — качественно, ~4 шага, нужен диск под ~12 ГБ;
   - **InstructPix2Pix** — быстрее и проще, 15–25 шагов, больше скорости @ guidance.
3. Задайте размер, seed и (для FLUX) квантизацию GGUF (Q4_K_M — баланс).
4. Запустите. При нехватке памяти размер уменьшится автоматически; включите «Восстановить исходный размер», чтобы результат растянулся обратно.

### ✨ Вкладка «Преображение»

> Оживление фото: изображение превращается в короткое видео. Нужен GPU.

1. Загрузите фото **или** введите промпт — тогда первый кадр сгенерирует SD 1.5, и оживится он.
2. При желании добавьте негативный промпт (что исключить из генерации).
3. Выберите разрешение (до 576p), длительность (1–4 сек) и масштаб итогового видео.
4. Запустите анимацию — SVD-XT сгенерирует до 25 кадров @ 6 fps, видео соберётся в H.264.

```text
├── outputs/                   # результаты (в .gitignore)
├── download_models.py         # загрузчик моделей
├── requirements.txt
├── .gitignore
└── README.md
```

### Разделение интерфейса и логики

Визуальная часть вынесена в `app/ui/`: разметка Gradio находится в `layout.py`, CSS — в `styles/app.css`. Обработчики событий и функции обработки данных остаются в `app/main.py`, а специализированные алгоритмы — в отдельных модулях `app/`. Поэтому внешний вид и структуру вкладок можно менять отдельно от алгоритмов обработки.

## Диагностика

Если приложение не запускается:

1. Убедитесь, что активировано нужное виртуальное окружение и установлены зависимости из `requirements.txt`.
2. Проверьте наличие файлов моделей в `models/`.
3. Для GPU-процессов проверьте `torch.cuda.is_available()` и список провайдеров ONNX Runtime.
4. Проверьте свободную RAM/VRAM и место на диске. Большие диффузионные модели могут занимать много памяти.
5. Посмотрите сообщение об ошибке в терминале запуска.

Чек-лист команд:

```bash
# Провайдеры ONNX
python -c "import onnxruntime as ort; print(ort.__version__, ort.get_available_providers())"

# Torch CUDA
python -c "import torch; print(torch.__version__, torch.cuda.is_available())"

# Видна ли GPU?
nvidia-smi
```

Если CUDA в списке провайдеров есть, но face-swap уходит на CPU — смотрите блок `[GPU] ---- ОТЛАДКА ----` в логах при запуске: там видны результат тестовой сессии, найденные nvidia-пакеты и точная причина.

- Код приложения свободен для личных и исследовательских проектов.

- Используйте инструмент этично: обрабатывайте только те изображения, на которые у вас есть право и согласие изображённых людей.
