# FaceSwap Webapp

Локальное приложение на Gradio для замены лиц на фотографиях и видео, AI-инпейнта, редактирования изображений по текстовому запросу и анимации фотографий.

> Обрабатывайте только изображения и видео, на использование которых у вас есть права и согласие изображённых людей. Не используйте приложение для обмана, выдачи синтетических материалов за подлинные или нарушения приватности.

## Возможности

| Раздел | Что делает |
|---|---|
| **Фото** | Находит до шести лиц на целевом снимке и заменяет выбранные лица; поддерживает выбор качества и формата результата. |
| **Видео** | Находит уникальные лица в выбранном фрагменте, позволяет сопоставить их с лицом-источником и сохранить звук. |
| **Выделение** | Восстанавливает выделенную область OpenCV или локальной inpainting-моделью. |
| **Редактор** | Редактирует изображение по текстовому запросу с помощью FLUX.2 klein или InstructPix2Pix. |
| **Преображение** | Создаёт короткое видео из изображения с помощью Stable Video Diffusion. |

После загрузки моделей вычисления выполняются локально. Для первоначальной установки моделей требуется интернет.

## Системные требования

- Python 3.10–3.12 (рекомендуется 3.11).
- Windows 10/11 или Linux. Другие платформы могут требовать самостоятельной настройки зависимостей.
- Для замены лиц доступен CPU-режим; NVIDIA GPU ускоряет обработку.
- Для вкладок **Выделение**, **Редактор** и **Преображение** требуется NVIDIA GPU с CUDA.
- Рекомендуется от 16 ГБ RAM; для тяжёлых генеративных моделей потребуется дополнительное место на диске и видеопамять.

## Установка и запуск

```bash
git clone https://github.com/EvgenyAlex21/FaceSwap-Webapp.git
cd FaceSwap-Webapp

python -m venv .venv

# Windows PowerShell
.venv\Scripts\Activate.ps1

# Linux
# source .venv/bin/activate

python -m pip install --upgrade pip
pip install -r requirements.txt

# Скачать базовые модели для замены лиц
python download_models.py

# Запустить приложение
python -m app.main
```

Откройте http://127.0.0.1:7860.

Приложение запускается на локальном интерфейсе `127.0.0.1` и не включает публичный Gradio Share.

## Загрузка дополнительных моделей

Запускайте команды из корневой папки репозитория. Базовые модели Face Swap загружаются всегда; флаги добавляют соответствующие наборы:

| Команда | Дополнительные модели |
|---|---|
| `python download_models.py` | Только базовые модели Face Swap (`buffalo_l`, `inswapper_128`) |
| `python download_models.py --inpaint` | Модели инпейнта: Realistic Vision, LUSTIFY, TryOffAnyone |
| `python download_models.py --editor` | FLUX.2 klein 4B GGUF |
| `python download_models.py --ip2p` | InstructPix2Pix |
| `python download_models.py --animate` | Stable Video Diffusion |
| `python download_models.py --translate` | Офлайн-переводчик RU→EN |
| `python download_models.py --all` | Все перечисленные наборы |
| Добавить `--force` | Принудительно скачать базовые файлы заново |

Модели сохраняются в `models/` в корне проекта. Загрузчик пропускает уже существующие файлы подходящего размера. Генерируемые результаты сохраняются в `outputs/`.

## Настройка NVIDIA CUDA

Для `onnxruntime-gpu` и PyTorch нужны совместимые версии драйвера NVIDIA, CUDA и cuDNN. Конкретные версии зависят от платформы и установленной версии PyTorch. Для Windows один из вариантов установки runtime-пакетов:

```bash
pip install onnxruntime-gpu==1.20.2
pip install nvidia-cublas-cu12 nvidia-cuda-runtime-cu12 nvidia-cudnn-cu12 nvidia-cuda-nvrtc-cu12
```

Установка PyTorch с CUDA (пример для CUDA 12.4):

```bash
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu124
```

Проверка окружения:

```bash
python -c "import onnxruntime as ort; print(ort.get_available_providers())"
python -c "import torch; print(torch.__version__, torch.cuda.is_available())"
nvidia-smi
```

Если CUDA-провайдер недоступен, замена лиц может перейти на CPU. Генеративные вкладки требуют доступной CUDA.

## Структура проекта

```text
FaceSwap-Webapp/
├── app/
│   ├── main.py              # точка входа и обработчики/бизнес-логика
│   ├── ui/
│   │   ├── __init__.py
│   │   ├── layout.py         # Gradio-компоненты, вкладки и привязка событий
│   │   └── styles/
│   │       └── app.css       # визуальное оформление интерфейса
│   ├── swapper.py            # детекция и замена лиц
│   ├── inpaint.py            # OpenCV и AI-инпейнт
│   ├── editor.py             # редактирование по промпту
│   ├── animator.py           # генерация видео из фото
│   ├── translate.py          # перевод промптов RU→EN
│   ├── vram.py               # управление выгрузкой моделей и VRAM
│   ├── gpu_utils.py          # проверка и настройка GPU
│   └── utils.py              # общие операции с файлами/видео
├── download_models.py        # загрузчик моделей
├── requirements.txt
├── .gitignore
└── README.md
```

### Разделение интерфейса и логики

Визуальная часть вынесена в `app/ui/`: разметка Gradio находится в `layout.py`, CSS — в `styles/app.css`. Обработчики событий и функции обработки данных остаются в `app/main.py`, а специализированные алгоритмы — в отдельных модулях `app/`. Поэтому внешний вид и структуру вкладок можно менять отдельно от алгоритмов обработки.

## Диагностика

Если приложение не запускается:

1. Убедитесь, что активировано нужное виртуальное окружение и установлены зависимости из `requirements.txt`.
2. Проверьте наличие файлов моделей в `models/`.
3. Для GPU-процессов проверьте `torch.cuda.is_available()` и список провайдеров ONNX Runtime.
4. Проверьте свободную RAM/VRAM и место на диске. Большие диффузионные модели могут занимать много памяти.
5. Посмотрите сообщение об ошибке в терминале запуска.

## Лицензии моделей

Репозиторий не включает веса моделей. InsightFace/InSwapper, Realistic Vision, LUSTIFY, TryOffAnyone, FLUX.2 klein, Stable Video Diffusion и InstructPix2Pix распространяются на условиях собственных лицензий. До коммерческого или публичного использования проверьте актуальные лицензии и ограничения каждой модели.
