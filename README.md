# Local Face Swap

Современный полностью локальный face-swap для **фото и видео**.

- Без лимитов
- Без облака  
- Без водяных знаков
- Поддержка **нескольких лиц**

## Возможности

- Красивый тёмный интерфейс
- Определение лиц с нумерацией прямо на фото
- Замена одного или сразу нескольких лиц (`0,1,2`)
- Фото + Видео
- Работает на NVIDIA GPU и на CPU

## Быстрый старт

```bash
# 1. Перейти в папку проекта
cd local-faceswap

# 2. Создать виртуальное окружение
python -m venv venv

# Linux / macOS
source venv/bin/activate

# Windows
# venv\Scripts\activate

# 3. Установить зависимости
pip install -r requirements.txt

# 4. Скачать модели (один раз, ~350 МБ)
python download_models.py

# 5. Запустить
python app/main.py
```

Откроется браузер: **http://127.0.0.1:7860**

## Как пользоваться

### Фото
1. Загрузите фото с нужным лицом (источник)
2. Нажмите **Найти лица** — появятся номера
3. Загрузите целевое фото
4. Нажмите **Найти лица**
5. Укажите индексы (например `0` или `0,1`)
6. Нажмите **Заменить лицо**

### Видео
1. Загрузите фото лица-источника
2. Загрузите видео
3. Укажите, какие лица менять
4. При необходимости ограничьте длину
5. Нажмите **Заменить лицо в видео**

## Требования

- Python 3.10 – 3.12
- Рекомендуется NVIDIA GPU (от 6 GB VRAM)
- Можно работать на CPU (медленнее)

### Если нет GPU / ошибка CUDA

```bash
pip uninstall onnxruntime-gpu
pip install onnxruntime
```

## Примечания

- Модели InsightFace / InSwapper. Перед коммерческим использованием проверьте лицензии.
- Результаты сохраняются в папку `outputs/`.
